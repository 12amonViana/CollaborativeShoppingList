# Instalação e primeiros passos

## Requisitos do dispositivo

- Android 8.0 (API 26) ou superior.
- Conexão com a internet.
- Permissão para instalar aplicativos de fontes externas, quando o APK não vier de uma loja oficial.

## Instalar pelo APK

1. Transfira o arquivo `ListaDeCompras-v1.0.apk` para o dispositivo.
2. Abra o arquivo pelo gerenciador de arquivos.
3. Se solicitado, autorize a instalação de aplicativos desconhecidos para o aplicativo usado para abrir o APK.
4. Toque em **Instalar**.
5. Ao terminar, toque em **Abrir**.

> O APK não é mantido no repositório GitHub. Ele deve ser distribuído separadamente pelo responsável pelo projeto.

## Atualizar uma instalação existente

Instale o APK mais recente sobre a versão atual. A atualização preserva os dados locais quando o pacote e a assinatura são compatíveis. Não desinstale primeiro, pois a desinstalação remove dados locais do aplicativo.

## Criar a primeira conta

1. Abra o aplicativo.
2. Escolha a opção de cadastro.
3. Informe nome, e-mail e senha.
4. Entre com a conta criada.
5. Digite o nome da primeira lista e toque em **Criar**.

## Entrar em uma lista compartilhada

1. Entre no aplicativo com sua conta.
2. Na tela **Minhas listas**, toque em **Entrar com código**.
3. Digite o código recebido do proprietário.
4. Confirme o ingresso.

O código é de uso único, expira após 3 horas e não funciona se a lista já estiver encerrada.
